# 一念木鱼 v1.2 · 开机即在

30 秒，1920 × 1080，30 fps，H.264 + AAC。延续苹果式产品短片的留白与节奏：暖白、木色、玻璃特写、快速拉远、连续位移和缩放，以真实像素庭院作为画面主体。

## 分镜

| 时间 | 展示内容 |
| --- | --- |
| 0–2.5 秒 | 从玻璃特写拉远，完整呈现纯胶囊；「清静，先一步。」 |
| 2.5–6.5 秒 | 点击开启自启动，桌面出现后胶囊停在右上角；「开机，就在。」 |
| 6.5–10.5 秒 | 从右上移到右下，缩放时仍保留角落；「右上，或右下。」 |
| 10.5–14.5 秒 | 指针抓住庭院，连续拖动到不同位置；「随手一拖，自在摆放。」 |
| 14.5–18.5 秒 | 自由缩放，尺寸刻度同步变化，展示 240–800 px 并停在 517 px |
| 18.5–22 秒 | 玻璃旋钮、像素庭院与昼夜光影随时间流转 |
| 22–24.5 秒 | 08:00–12:00、14:30–17:30 两段自动轻敲 |
| 24.5–26.5 秒 | 夜间停止敲击，安静陪伴 |
| 26.5–30 秒 | 产品图标、名称、v1.2、Mac / Windows 与开源地址 |

## 画面和声音

胶囊素材来自实际应用的 CPU 像素世界与 WebGL2 玻璃引擎，以固定时钟逐帧采集。v1.2 新增的是桌面宿主的自启动与停靠行为，像素庭院沿用同一引擎画面。桌面、开关、停靠路径、指针、尺寸刻度和文字是独立演示动效；开机段用动效表达登录后的产品行为，未录制系统重启过程。

使用产品自身合成的木鱼原声，共 15 次。敲击镜头按每秒一声对齐，启动、停靠和夜间段保留静音，片尾有一次收尾音。沿用无旁白、无背景音乐的版本。

## 可编辑工程

解压 `Yinian-Muyu-v1.2-ChatCut-Project.zip`，用 ChatCut 打开其中的 `一念木鱼-v1.2-开机即在.chatcutproject`。

工程保留 1 条新版时间线、6 条轨道、43 个剪辑项与 9 项所用素材。真实产品画面、桌面舞台、指针与功能标注、标题和声音分别保存。`Title.tsx`、`Desktop.tsx`、`Interaction.tsx` 使用 ChatCut Motion Graphic 运行时；文案、配色、字体、指针轨迹和模式可编辑。属性清单与分镜随工程附带，媒体全部采用相对路径。

字体为 Noto Serif SC、Noto Sans SC 与 Inter，由编辑环境提供；字体文件未随包分发。换机器编辑时请确认这三款字体可用。旧版视频和工程保留在 v1.1 Release。
