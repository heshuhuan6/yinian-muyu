# 一念木鱼 v1.1 · 自由胶囊宣传片

30 秒，1920 × 1080，30 fps，H.264 + AAC。暖白留白、玻璃特写、快速拉远、连续拖动和缩放，沿用上一版简洁的产品广告风格。

## 这版展示什么

| 时间 | 画面 |
| --- | --- |
| 0–3 秒 | 从玻璃特写拉远，完整展示纯胶囊 |
| 3–7 秒 | 指针抓住庭院，在桌面不同位置自由摆放 |
| 7–11 秒 | 连续放大、缩小，再停在 517 px；尺寸刻度同步变化 |
| 11–13.5 秒 | 新版设置界面，强调精确输入宽度 |
| 13.5–15.5 秒 | 收起设置，回到纯胶囊；位置与大小自动记住 |
| 15.5–19 秒 | 从早晨到夜间，玻璃旋钮与像素光影流转 |
| 19–23.5 秒 | 每日时段自动敲击，其他时间静候 |
| 23.5–27 秒 | Mac 与 Windows，离线运行 |
| 27–30 秒 | 产品图标、名称与开源地址 |

## 画面和声音

像素世界由 v1.1 实际 WebGL2/CPU 引擎以固定时钟逐帧输出，透明 VP9 素材保留玻璃边缘。新版设置图来自同一应用。指针、移动路径、连续缩放、尺寸刻度和文字是独立的演示动效，用于在短片中清晰呈现交互；此片采用应用引擎输出，未使用系统桌面录屏。

木鱼声来自产品自身的 WoodSound。敲击镜头按每秒一声对齐；夜间静候段留白，片尾有一次品牌收尾音。沿用无旁白、无背景音乐的版本。

## 可编辑工程

解压 `一念木鱼-v1.1-宣传片-ChatCut工程.zip`，用 ChatCut 打开其中的 `一念木鱼-v1.1-自由胶囊.chatcutproject`。真实产品画面、辅助产品画面、指针与尺寸标注、标题和声音分轨保存。Title.tsx 与 Interaction.tsx 使用 ChatCut 的 Motion Graphic 运行时；文案、配色、字体和指针轨迹均有可编辑属性。

工程只包含新版时间线与 9 项所用素材，全部为相对路径。系统和 ChatCut 字体未打包。`逐帧采集.mjs` 留作再生成参考，其中路径需按编辑机器调整。旧版宣传片与原工程仍保留。

## 检查

完整解码通过：900 帧，30 秒，1080p，30 fps；音轨为 48 kHz 双声道 AAC，峰值 -13.6 dB。未检出黑帧段或超过 3 秒的异常冻结。核对了拖动轨迹、缩放指针、517 px 设置框、昼夜变化、文字进出场和片尾。导出文件抽帧与 ChatCut 时间线一致。工程内素材引用齐全。
