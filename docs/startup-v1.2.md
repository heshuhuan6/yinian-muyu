# 一念木鱼 v1.2 · 开机自动出现

像一个小桌面挂件：开机并登录后，纯胶囊自动出现在你选的角落，恢复大小与每日敲击时段。

## 开启

1. Mac 将 `一念木鱼.app` 放入“应用程序”，再双击打开。Windows 完整解压 ZIP，把整个文件夹放到准备长期使用的位置，再运行 `YinianMuyu.exe`。
2. 右键胶囊，或右键顶部状态栏 / 系统托盘图标，勾选“开机自动启动”。
3. 在同一菜单选择右上角或右下角。左上、左下、自由拖动也继续支持。

只需要设置一次。以后登录当前账户时自动显示胶囊；从真实时间开始运行，按保存的时段敲击，声音仍默认关闭。窗口不会抢走其他应用的键盘焦点。

## 大小与位置

支持 240–800 px 连续宽度，拖动、滚轮和精确数字输入都保留。选择角落后缩放仍贴着该角落；右下角避开 Dock 或任务栏。展开设置时，整个面板会限制在可见工作区内，关闭后回到所选角落。新用户默认右上角；升级保留已有位置。

## 关闭或调整

- 在同一菜单取消“开机自动启动”，当前胶囊可以继续使用。
- Mac 也可在“系统设置 → 通用 → 登录项与扩展”管理；若菜单显示“待系统允许”，使用下面的“在系统设置中允许…”入口。
- Windows 也可在“设置 → 应用 → 启动”管理。Windows 便携包移动到新文件夹后，在新位置重新开启自启动。
- 应用读取系统实际状态，系统中关闭后不会在下次打开时重新强制开启。
- 网页离线版继续作为网页使用；自动启动由 Mac / Windows 桌面版提供。

## 实现与检查

Mac 采用 [SMAppService.mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp)；Windows 使用 [Electron 登录项接口](https://www.electronjs.org/docs/latest/api/app/#appsetloginitemsettingssettings-macos-windows)。不需要管理员权限，不增加驻守进程。

Mac 的 40 项原生检查与 11 项登录项状态测试通过。实际在用户应用程序目录完成开启、关闭、再次开启，并在系统“登录时打开”列表确认一念木鱼。检查了右下角缩放、设置向上展开、关闭恢复和偏好重载。验证使用冷启动与系统登录项状态，没有重启或注销当前工作中的电脑。

开发者可用应用包内的 `Contents/MacOS/Muyu --login-item status` 查看系统状态；`enable` / `disable` 是显式安装与验收入口，正常启动不会调用它们。`bash native/test-login.sh` 执行隔离状态测试，不修改系统登录项。

Windows 通过 19 项单元测试、27 项功能验收、6 项最终 EXE 检查与 8 项真实登录项专项验收。使用含空格的最终 EXE 路径执行实际登录命令，检查系统禁用、明确重新开启、取消、重开偏好、重复启动及不抢焦点；测试后恢复原启动项和设置。正常登录命令启动后的进程为零 TCP / UDP 端点。未注销或重启 Windows 工作机。
