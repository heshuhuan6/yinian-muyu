一念木鱼 · Windows 便携版

1. 将整个 ZIP 解压到一个文件夹。
2. 双击 YinianMuyu.exe 即可使用。保留同文件夹内所有文件。
3. 默认显示于左上角并保持置顶。右键木鱼，或右键系统托盘图标，可切换右上角、显示大小、显示屏、置顶、隐藏及退出。

时间自动跟随本机当地时间。拖动玻璃滑块可停留在 00:00—24:00 任意时刻进行预览；点击“回到当前时间”恢复。预览也会按所选时刻演示敲击。
每日默认在 08:00—12:00、14:30—17:30 敲击，开始时间包含、结束时间不包含。可编辑、增加或删除时段（最多 6 段），支持跨午夜；重叠不会重复计数。
默认每分钟 60 次，可改为 40 或 90。声音默认关闭，可手动开启；声音在本机合成。
隐藏、最小化、锁屏或休眠会暂停；恢复不补敲。窗口显示但失去焦点时仍运行。关闭窗口会隐藏至托盘；请在托盘菜单中选择“退出一念木鱼”。

无需安装 Node、Python 或浏览器，无需联网。没有自动更新、遥测、账号或外部素材。
设置保存于当前用户 AppData\Roaming\一念木鱼\settings.json；声音和本次计数不跨启动保存。
本发行版为 Windows x64 便携 ZIP，包含 Chromium 运行时；尚未进行代码签名。
