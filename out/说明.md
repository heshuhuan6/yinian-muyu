# 一念木鱼

玻璃胶囊里的像素小庭院。木鱼坐在软垫上，木槌随节奏抬起、敲下和回弹；每一声在池水里留下一圈涟漪。小猫听一会儿，时段结束就蜷起来休息。

## 打开与使用

- **Mac 版**：双击 `一念木鱼.app`，新用户默认在桌面右上角显示 480 px 宽的纯胶囊，底部时间、计数和时段全部隐藏。右键胶囊或顶部状态栏图标，可以编辑时段、精确调节大小、置顶或退出。
- **Windows 版**：完整解压 Windows ZIP，双击文件夹中的 `YinianMuyu.exe`；右键小窗或系统托盘图标可以切换角落、大小和置顶。
- **网页版**：双击 `一念木鱼.html`，使用浏览器打开。代码与样式全部内嵌，支持离线使用。
- 声音默认关闭。点击“开启声音”后，在敲击时段内播放本机合成的木鱼声。
- 默认节奏每分钟 60 次，可选 40、60、90 次。次数是本次打开以来的敲击次数，可按 ↺ 清零。

## 按时间自动敲击

玻璃旋钮是连续的时间滑块，左端 00:00，右端 24:00。正常运行时跟随电脑当地时间，包含秒与毫秒；经过一天缓慢移动。木鱼是否敲击由每日时段决定。

默认每天：

| 时间 | 行为 |
| --- | --- |
| 00:00–08:00 | 静候 |
| 08:00–12:00 | 自动敲击 |
| 12:00–14:30 | 午休，停止敲击 |
| 14:30–17:30 | 自动敲击 |
| 17:30–24:00 | 静候 |

开始时刻包含在时段内，结束时刻起停止。例如 12:00:00 已进入午休，14:30:00 开始下午时段。

桌面版右键打开设置面板（Mac 为“编辑每日敲击时段”，Windows 为“打开设置与每日时段”）；网页版点击“每日敲击时段”。设置里的“完成”或 Escape 会关闭面板，回到纯胶囊。起止时间修改后即时保存，最多添加六段，也可删除时段。支持跨午夜，例如 22:00–02:00；重叠时段合并判断，不会重复敲击。全部删除后保持静候。开始和结束相同会显示错误，并保留最后一次有效设置。

网页版保存到当前浏览器的本地存储；Mac 版保存到应用偏好设置，Windows 保存到本机 AppData，重开应用后继续使用。时段每天重复。

## 自定义大小与位置（v1.1）

- 拖动庭院区域移动整个胶囊；按住 Alt/Option 也可以从玻璃上开始移动。
- 拖动玻璃旋钮仍然连续预览时间，两种手势分开判断。
- 滚轮缩放；悬停时右下角出现小手柄，可拖动等比例调节。
- 右键打开设置，在“胶囊大小”一栏用滑条或数字输入指定 240–800 px 宽度，例如 517 px。Mac 也可通过“显示大小 → 自定义大小…”直接打开。
- 自由位置、尺寸、屏幕与置顶状态保存到本机，重开时恢复；右键可一键返回屏幕四个角落。
- 打开设置时窗口临时扩展并避开屏幕边缘，关闭后恢复原来的胶囊位置。

## 开机自动启动（v1.2）

将桌面应用放到长期使用的位置，右键勾选“开机自动启动”，再选择右上角或右下角。开机并登录当前账户后，纯胶囊自动出现，恢复大小、位置与每日时段，跟随当前真实时间，默认静音。

Mac 使用系统登录项，Windows 使用当前用户的启动项；菜单读取系统真实状态，取消勾选即可关闭。新用户默认右上角，旧位置保留。底部停靠避开 Dock / 任务栏，缩放保持角落，设置展开后关闭恢复原位。若 Mac 显示“待系统允许”，菜单提供系统设置入口。Windows 便携文件夹移动后请重新开启自启动。

## 手动连续预览

- 拖动玻璃可停在任意中间位置，不吸附到两端，时间精度保留为连续数值。
- 手动拖动后显示“时间预览”，庭院和敲击状态按预览时间变化；松手后保留该位置。
- 点击“回到当前时间”，立即恢复实际时间及真实每日时段。
- ← / ↓ 减少 15 分钟；→ / ↑ 增加 15 分钟；按住 Shift 为每次 60 分钟。
- Home 到 00:00，End 到 24:00。Enter / Space 恢复当前时间。

预览模式的时刻用于体验该时刻的效果。要让木鱼按真实时间日常运行，保持“正跟随现在”。

## 渲染与声音

Vite + React 19 + TypeScript strict + 普通 CSS。React 只创建静态结构，一个 effect 挂载引擎；逐帧状态由引擎管理。

- 世界为 144×76 CPU 像素缓冲，每帧重新绘制，使用最近邻采样。全屏网页优先按完整设备像素倍率放大，显示上限约 800×420 CSS px；桌面按用户选定的精确尺寸显示，世界纹理始终最近邻采样。
- 景物由填充矩形、多边形、椭圆构成。主要精灵自动生成一像素外轮廓，上亮下暗。
- 月色、清晨、杏色光、暖茶光四套材质色。按 4×4 Bayer 阈值选择相邻调色板颜色，像素内部不混色。
- 一天时间决定光照：06–08 渐亮，08–17 白天，17–20 渐暗，其余为夜间；房间颜色平滑变化。敲击时段独立于天光，例如午休仍是明亮的庭院。
- 单个 WebGL2 片元着色器绘制约 1.28 倍玻璃放大、折射、RGB 边缘色散、暗带、亮边、高光、Fresnel 染色与柔和阴影。发光缓冲单独模糊合成。
- 不支持 WebGL2 或丢失上下文时切换到 2D 像素画面与简洁玻璃环。
- 弹簧跟随指针，拖动时更紧；速度产生拉伸与反向压缩，加速度产生阻尼摆动。松手不吸附。
- 随机布局、微尘与声音噪声均使用固定种子的 xorshift。声音使用 Web Audio 阻尼正弦振荡器和短噪声脉冲合成，无外部音频、图片和字体资源。
- 所有引擎监听器绑定一个 AbortController；卸载时取消 RAF、终止监听器、删除 GL 对象并关闭音频上下文。兼容 StrictMode 重复挂载。

减少动态效果时，场景与玻璃即时定位并保持静止；时段判断和计数继续工作。

## 演示与复现

网址加 `?demo=1` 自动演示拖动时间，依次经过晨间、午休、下午，再返回。首次真实指针或键盘输入接管。

控制台 `window.__render(t)` 以秒为单位，从新模拟和新像素世界开始，用固定 60 Hz 时钟推进。复现模式使用默认时段与 60 次/分钟；同一视口和动态效果偏好下，相同时间生成相同画布字节。

`window.muyu.inspect()` 可查看时间模式、连续分钟值、时段、计数、渲染后端和音频状态。`?renderer=2d` 可查看回退。

## 运行条件与已知事项

- 按时运行需要应用保持打开、电脑处于唤醒状态。Mac 隐藏控件会暂停，重新显示或唤醒后按当前时段继续，不补敲错过的次数。网页版切到后台标签页也会暂停，返回后重新校准。
- 声音需主动开启，每次重新打开默认静音。
- Mac 应用采用临时签名，其他 Mac 首次运行可能需在系统设置的“隐私与安全性”允许打开。Windows 包未签名，可能显示 SmartScreen 发布者提示。
- Windows 11 x64 已实测；Windows 10 尚未进行第二台实体机验收。Windows 休眠/唤醒检查采用系统事件模拟。
- 本次手机检查为 Chrome 模拟视口；实体 iPhone 未进行验收。
